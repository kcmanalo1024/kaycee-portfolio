01 — THE IDEA

A little less chaos. A little more clarity.

Karibok is a Batangueño word for kagulo, chaos, or confusion. The name reflects the everyday mess of tasks, deadlines, projects, and ideas that the website aims to organize.

Karibok is a productivity web app designed to help users manage tasks, organize projects, track deadlines, and monitor progress in one place. The project is currently in development, starting with the interface and user experience before gradually building its core functionality.

02 — CURRENT STATUS

Building the experience, one version at a time.

UI/UX design and prototyping are part of the current development phase. The front end is being built with React, Tailwind CSS, and JavaScript. Public interface previews are coming soon.
