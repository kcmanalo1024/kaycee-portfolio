Adobe XDFigmaVS Code
01 — OVERVIEW

A safe, easy-to-use EMR concept.

MediTrack is a concept EMR system for doctors and patients. The tagline, "Records Right, Day or Night," reflects the goal: keeping medical records accurate and safe ("records right") while making them available anytime ("day or night") — reliable for both doctors and patients.

Low-fidelity wireframes were built in Adobe XD, with the interactive prototype designed in Figma. Screens shown here were coded in VS Code for the activity, with no backend attached. Figma access was later lost, since the account used an LPU email that could no longer be used after graduation.
