# keysimadeit — Kaycee Manalo Portfolio

A responsive portfolio built with HTML, CSS, Tailwind CSS via CDN, and vanilla JavaScript.

## Run locally
1. Extract this folder.
2. Open it in VS Code.
3. Install the **Live Server** extension (recommended).
4. Right-click `index.html` → **Open with Live Server**.

No Node.js, React, or build process is required.

## Main pages
- `index.html` — portfolio home
- `tubaland.html` — Tubaland case study
- `cdp.html` — CDP Web Application case study
- `packd-up.html` — Pack’d Up case study

## Branding
The portfolio uses **keysimadeit** as the personal creative brand. You can change it globally by searching for `keysimadeit` in the HTML files.

## Google Play
The Tubaland button currently opens a Google Play search for “Tubaland”. If you have the exact app listing URL, replace that href in `index.html`.

## Assets
All supplied project screenshots, certificates, standees, resume, case-study document, and the two uploaded personal photos are included under `assets/` and `documents/`.
